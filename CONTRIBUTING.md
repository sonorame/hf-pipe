# Руководство для контрибьюторов

Требования к окружению: Node.js 20+.

## Сборка и запуск тестов

Перед отправкой изменений запустите проверку типов и набор автоматических тестов:

```bash
npm install
npm test
```

## Правила репозитория

- Запрещено коммитить файлы с секретами (`.env`, `matrix-session.json`), PID-файлы (`*.pid`), снимки экрана и каталог `node_modules`.
- В текстах документации и пользовательских сообщениях не допускается упоминание приватных путей, учетных записей или локальных стендовых имен.
- Русские тексты должны следовать правилам типографики: кавычки только `"`, тире только `-`, буква е без точек наверху.
