# Domain docs

This is a single-context repository.

Before exploring a relevant area, read `GLOSSARY.md` at the repository root and ADRs under `docs/adr/` when they exist. If they do not exist, proceed silently; create them only when a term or decision needs recording.

Use glossary terminology in issue titles, proposals, hypotheses, and test names. Surface a conflict with an existing ADR instead of silently overriding it.
