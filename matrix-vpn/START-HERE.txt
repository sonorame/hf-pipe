ЭТО ПАКЕТ ДЛЯ БЫВШЕЙ DIRTY — РАБОЧЕГО НОУТБУКА.

1. Полностью распакуй ZIP в отдельную папку.
2. Запусти Start-VPN.cmd от своего обычного пользователя Windows.
   Первый запуск откроет вход в Matrix: подтверди свой аккаунт.
   Затем подтверди запрос администратора для виртуального адаптера.
3. Запусти Check-VPN.cmd: он проверит трубу, IP VPS и Telegram HTTPS.
   В Codex отправь: Ответь только HF_PIPE_OK. Не используй инструменты.

Выключить: Stop-VPN.cmd. После него сеть должна вернуться в исходное состояние.
Проверить статус трубы: http://127.0.0.1:18864/
Логи: %USERPROFILE%\.hf-pipe\matrix-vpn

На домашнем ноутбуке проверены транспорт, Codex, IP VPS, Telegram HTTPS,
DNS через VPS, восстановление после обрыва и штатное завершение frontend.
Виртуальный адаптер, маршруты и доступность TURN из рабочей сети
сегодня проверить невозможно: это первая проверка на рабочем ноутбуке.

Первая версия передаёт публичный IPv4 TCP и DNS. Звонки Telegram,
прочий UDP и IPv6 пока не поддерживаются. Возможны сетевые таймауты.

Основной чистый ПК использует ДРУГОЙ архив: hf-pipe-work-clean.zip.
Не заменяй его настройку этим пакетом.

Архив содержит одноразовую привязку отдельного устройства. Не публикуй его.
